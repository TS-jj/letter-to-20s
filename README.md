# 给20岁自己的生活建议

一封写给自己的信 —— 由一份 Word 文档做成的互动长页。

## 线上地址（直接分享这个）

https://ts-jj.github.io/letter-to-20s/

手机、电脑打开都能看，**点开信封就会自动响起背景音乐**。

## 内容

- 18 个章节 · 10 句话 · 约 2900 字
- 信封开场、章节时间轴、人生轨迹图、抽一句、写给未来的自己、夜读模式
- 背景音乐《不完美小孩》

## 文件说明（重要）

这个站点由**两个文件**组成，缺一不可：

| 文件 | 大小 | 作用 |
|---|---|---|
| `index.html` | 约 75 KB | 页面本体，秒开 |
| `music.mp3` | 约 4 MB | 背景音乐，与页面并行加载 |

`index.html` 会在同目录下自动寻找 `music.mp3` 并播放，所以**两个文件必须放在一起**。
只传 `index.html` 会变成「有页面、没声音」。

想改成单个文件（把音乐内嵌进 HTML、可离线双击打开）也可以，
代价是文件会变成约 5.4 MB、打开明显变慢 —— 一般不需要。

## 说明

要改内容：编辑仓库里的 `index.html` 并提交，Pages 会自动重新构建（约 1 分钟）。
